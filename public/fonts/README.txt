Place the B Davat font file(s) in this directory.

Accepted file names (any one of these will work — woff2 preferred for size):
  - BDavat.woff2
  - BDavat.woff
  - BDavat.ttf
  - BDavat.otf

The @font-face declaration lives in src/app/globals.css. If you need to
support multiple weights, duplicate that @font-face block per weight and
adjust the filename + font-weight value accordingly.
